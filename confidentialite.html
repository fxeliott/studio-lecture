Règles de confidentialité de Studio lecture(mises à jour le 7 octobre 2026)

  1. Données lues : statistiques, publications, commentaires et profil des comptes Instagram et YouTube du propriétaire, et statistiques de ses publicités Meta, par les API officielles, en lecture seule.
  2. Où elles vont : uniquement sur l'ordinateur du propriétaire. Ni vendues, ni partagées, ni transmises à quiconque, ni utilisées pour de la publicité.
  3. Personnes qui commentent : leur nom d'utilisateur est remplacé par un alias dans tout ce que l'outil produit. Les données YouTube qui concernent des personnes sont supprimées ou rafraîchies sous 30 jours.
  4. Durée : les statistiques sont gardées tant qu'elles servent ; elles peuvent être supprimées à tout moment.
  5. YouTube : Studio lecture utilise les services d'API YouTube. Conditions d'utilisation de YouTube : https://www.youtube.com/t/terms. Règles de confidentialité de Google : https://policies.google.com/privacy.
  6. Retirer l'accès : Google, https://myaccount.google.com/permissions ; Instagram, Paramètres, Applications et sites web, Studio lecture, Supprimer.
  7. Suppression de vos données : écrivez à l'adresse d'assistance affichée sur l'écran d'autorisation ; la suppression est faite sous 7 jours.
  8. Aucun cookie, aucun traceur.
  9. L'usage des informations reçues des API Google respecte la Google API Services User Data Policy, y compris les exigences d'usage limité.
